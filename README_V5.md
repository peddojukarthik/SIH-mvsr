# SIH Secure DMS V5

## What changed
- External participants now have real case-scoped accounts.
- Invitation opens the Netlify `external-portal.html` page.
- External participant creates their own password. Passwords are bcrypt hashed and never emailed.
- External participant then logs in with email + self-created password.
- External sessions are separate from internal employee sessions.
- External access is limited to the case and authorized document types.
- Closing a case deletes all external participant account rows; external sessions cascade-delete.
- Case Head has a Close Case action.
- Case AI retrieval is more reliable: small cases send all processed chunks; larger cases use token scoring and a safe first-chunk fallback.
- AI Q&A uses Ollama first and Gemini fallback, with a bounded 45-second provider timeout for each chat provider.
- AI errors are returned with useful provider details instead of generic `Failed to fetch`.
- Native PDF text is reused; the document is not sent to an AI provider when PyMuPDF can read it.
- FIR records are stored as `pdf` in the database and the generated bytes are the bytes hashed/signed/stored.
- `fir_pdf.py` and `merkle.py` are included so the deployment package is self-contained.

## Render environment
Set:
`FRONTEND_URL=https://allaince.netlify.app`
`BASE_URL=https://alliance-cqnf.onrender.com`
`AI_CHAT_TIMEOUT=45`

Build command:
`pip install -r requirements_sih_case_ai.txt`

Start command:
`uvicorn invite_backend:app --host 0.0.0.0 --port $PORT`

## Supabase
Run the supplied migration after the previous Case AI migration. It is designed to be re-runnable. It adds external password/session fields and the case-close cleanup trigger.
